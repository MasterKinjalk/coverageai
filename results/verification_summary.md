## Not covered / blocked

* Real annotated cards: the Simoes et al. real cards (Zenodo 14010262) are a restricted record; the open record 13995950 holds only the 300 synthetic cards. The real-card tile evaluation is implemented (`dataset_real_tiles`) and runs automatically when the files are present. Criteria on real cards stay 'blocked: needs data access' until then.
* Stain counts: the renderer annotates every droplet while touching stains merge visibly, so count error against annotated droplets is bounded below by overlap; the count against connected components (`count_rel_err_vs_cc`) isolates the watershed quality. Simoes polygons are per droplet.
* Droplet-size outputs depend on the spread factor (1.6 to 2.2 in the renderer, assumed 1.9 by the readers) and, for the Simoes cards, on an inferred scale (76 mm card width / image width); neither is published.

## What to run to update these numbers

1. B1 full GPU training is DONE (27 epochs, bf16, best val Dice 0.969 / IoU 0.940, see `results/unet_train_log.csv`; GPU-host test eval in `results/b1_synthetic.json`, runtime there is NOT this laptop). 2. After any new weights: `uv run python experiments/eval_verifiers.py --verifiers b1 --merge` (about 15 to 30 min on CPU) refreshes the B1 rows here and writes the local re-evaluation `results/b1_synthetic_local.json`. Re-run it on an idle machine for clean runtimes (runtime is wall-clock and sensitive to other CPU load).
3. Real cards: request access to Zenodo record 14010262, unzip so that the files are `data/external/simoes2025/real/image/*.png` and `real/label/*.txt` (optional `real/px_per_mm.json` = {"default": px_per_mm}), then `uv run python experiments/eval_verifiers.py --merge` fills the real-tile rows and flips the three 'blocked' criteria to met/missed.
